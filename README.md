## 💡 学习心得

*   **传值调用**：安全，适用于只读取数据不修改的场景。函数拿到的是“复印件”。
*   **传址调用**：高效，适用于需要修改原变量或传递大块数据（如数组）的场景。函数拿到的是“原钥匙”。
*   **模块化设计**：高效，适用于多个分支功能需求。
*   **嵌套循环**：通过精准控制内外层循环的边界条件（如 `num - i`），能够解决复杂的图形打印与多维数据遍历问题。
